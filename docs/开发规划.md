## 0. 命名与定位

- **英白拉多 = Imperator**，拉丁语（罗马共和国士兵授予凯旋将军的称号，帝国时期成为皇帝头衔，词根 imperare「命令」）。《鸣潮》中黎那汐塔岁主英白拉多的权能为「分离」。README 末尾声明：仅受此启发命名，与 Kuro Games 无任何关联、未获背书。
- **图标设计**（assets/icon.svg）：拉丁字母 **IMPERATOR** 字样 + 罗马月桂花环（公共领域古典元素）+ 波形从中一分为二、分流而下的「分离」意象——同时呼应原名文字（拉丁语）与权能含义。
- **一句话定位**：自托管的智能音轨分离器——视频/音频进，BGM、每个说话人一条独立 WAV 出；重叠说话也能正确分配；所有轨按时长逐样本对齐，相加精确还原原声。
- **护城河**：①输出一致性契约（用户可验证）②可配置置信度+偶发排除策略层（可解释、可审计、可校准）③试听修正回路 ④国内零门槛模型分发。**模型可替换抽象**（MSS 后端/Embedder/重叠分离器均为注册接口）是对冲"统一模型时代到来"的架构要求。算法层全用现成开源权重，不自研不训练。

## 2. 核心流水线

```
输入(视频/音频)
  → ffmpeg 抽主轴 master(44.1k 立体声 f32, PCM 管道直读 numpy)
  → [MSS] audio-separator(master) → vocals + instrumental（44.1k，落盘）
  → [分析支线] vocals 降采样 16k 单声道（VAD/embedding/重叠分离的输入一律是去伴奏后的 vocals！）
  → [VAD] silero → 语音段
  → [Embedding] 滑窗(1.5s/步长0.75s) cam++ → L2 归一化向量
  → [聚类] 凝聚聚类(平均链接, cos ≥ τ 合并) → 本地说话人 + 段归属
  → [偶发排除] 聚类级(占比<比例/时长<下限→并入最相似) + 段级评分
  → [重叠检测·三触发] ①歧义窗(top1<τ 或 margin<δ) ②切人边界窗(前后窗归属不同人)
                       ③自洽性差窗(与自身质心相似度低)
  → [重叠分离] MossFormer2_SS(16k vocals 窗口, ±1.5s 上下文) → 双流 embedding 匹配：
      双流分别命中两个不同说话人(≥τ−0.05) → 重叠：软比率掩码
      仅单流命中 → 误触发：整窗硬归属命中者（m=1）
      零命中 → unknown/other
  → [账本重建] 时域包络掩码上采样 + 淡变互补 + 补集 → 分轨流式写盘
  → [QC] Σ断言 / 残差能量比 / 每轨语音占比 / 串音估计 / 审计
  → [输出] speaker_*.wav + bgm.wav + other.wav + residual.wav + timeline.json + report.html
```

### 2.1 掩码数学（写死，防止实现歧义）

- 掩码 = **时域幅度包络的软比率**，非 TF 域：`m_a(t) = |a16(t)|^p / (|a16(t)|^p + |b16(t)|^p + ε)`，p=2。段内严格 `m_a + m_b = 1`。
- 16k→44.1k 映射：**以时间戳（秒）为锚**做窗边界换算（`round(t·fs_out)`），掩码包络先在 16k 上平滑，再 `resample_poly` 上采样到主轴率，随后**归一化互补**（Σmᵢ 归一后再算 m₀）。
- 补集掩码 **m₀ := 1 − Σmᵢ，不截断**（淡变边界 Σmᵢ 可能瞬时 >1，m₀<0 保数学恒等，QC 记录负补集占比作健康指标）。
- 相邻段淡变**共用分区形状**：A 段淡出 `1−f`，B 段淡入 `f`（同一升余弦 f），保证逐样本 Σ=1。
- 单人段 m=1 硬归属；无人声段 m=0（精确静音）。

### 2.2 输出契约（需求 7 的无歧义表述）

用户可见的全部输出轨：

```
speaker_1..N.wav = mᵢ ⊙ vocals
bgm.wav          = instrumental
other.wav        = m₀ ⊙ vocals          （未归属人声：歌声/呼吸/惊呼）
residual.wav     = master − vocals − instrumental （MSS 自身不一致性，诊断轨）
```

**恒等式：Σ speaker + bgm + other + residual = master，逐样本浮点成立（<1e-5）**；每轨采样数 = 主轴精确采样数（时长与视频一致）；无人声处精确 0。最终可选 48k 重采样：全部轨同一 `resample_poly` 参数最后一步执行（线性算子与求和可交换）。QC 报告以 `max|Σ−master|` 断言。输出默认 float32 WAV（保精确相加），可选 s16/s24（量化误差另行说明）。

### 2.3 采样率策略

44.1k 主轴（MSS 原生域）+ 16k 分析支线（**从 vocals 派生**）；16k 算决策（归属/掩码），44.1k 重建 → 说话人轨天然全带宽。

### 2.4 边界与诚实声明

≥3 人重叠无开源权重 → 主导说话人 + `overlap_multi` 标记（UI/README 明示实验性）。主导型重叠（能量悬殊）召回有限 → README 能力边界一节明示。取消仅在阶段边界生效（torch forward 不可中断），UI 文案如实。

## 4. 偶发排除·自动模式评分函数

```
A(j→k*) = 0.35·σ((s₁−τ)/0.08) + 0.20·σ(margin/0.06) + 0.15·(1−min(d_j/d_ref,1))
        + 0.10·ctx_j + 0.10·exp(−|log(E_j/Ē_k*)|/σ_E) + 0.10·(1−p_ns)
A ≥ 0.62 → 并入 k*；A ≤ 0.35 → unknown；中间 → review 标记；分项分数全部进审计。
```

聚类级联动：占比 <4% 或 <5s 的簇 → 候选；质心与最近簇 cos ≥ τ−0.05 → 整簇并入，否则保留标记「可能偶发」。新建说话人需持续证据。默认保守：宁可 unknown 不强行合并。**全部魔法数可配置且校准脚本可重标定**；合成标注集（AISHELL/DiPCo 风格双人语音 + 注入咳嗽/惊呼/短切换/BGM）既做校准也做 e2e 验收数据（一鱼两吃）。

## 11. 风险与缓解

1. 级联误差（MSS 误删轻语音）→ 残差轨兜底 + VAD/轨道能量失配告警。
2. 主导型重叠召回有限 → 三触发信号尽力覆盖 + 能力边界明示（诚实）。
3. 模型下载失败 → 域名路由镜像链 + 断点续传 + 体积校验 + 离线 CLI。
4. OOM/长音频 → 内存模型按 (3+N)×master 估算；**账本流式分块写盘（逐窗 read-compute-write，RAM O(窗)**；MSS 依赖库内部分块，低显存自动轻量档 + 用后释放。
5. 阈值不可迁移 → 按模型存预设 + 校准脚本 + reliability 曲线。
6. 偶发排除掩盖真实切换 → unknown 兜底 + 审计 + 手动改派。
7. Windows 乱码 → chcp 65001 + SetConsoleOutputCP；Starlette 版本 pin ≥0.37。
8. clearvoice 临时文件 I/O → 统一 temp 目录管理、逐窗复用。

## 16. v1.1.0 更新（2026-10-20 用户需求）

新增「按说话人切出视频 / 导出音频」：

1. 导出页（新标签页 `/export.html?job=&track=&kind=`）：试听音轨、自动分析有声音片段、逐片段勾选、参数可调（能量阈值/相对阈值/合并间隔/最短片段/前后留白）。
2. 视频导出：逐段帧精确重编码（libx264，NVENC 自动探测回退），可选「保留原视频音频」或「使用分离音轨」；concat 流拼接 + ffprobe 校验时长/流。
3. 纯音频导出：片段拼接（5ms 接缝淡入淡出）或完整音轨；WAV/MP3/M4A/FLAC；纯音频输入也可用。
4. **时间轴对齐，不做二次相似度匹配**：切片边界来自已分离音轨在该时间段的能量，原混音中的 BGM/其他说话人不会影响切片判定。
5. 独立 ExportRunner 单 worker 队列，避让分离任务；ffmpeg 进度真实可取消；导出读源时与人工修正重渲染互斥；父任务删除时有活跃导出返回 409。
6. 测试：片段检测/校验、纯音频四格式、视频两种音频来源（频谱验证）、API 边界、真机 20s 全流程。
